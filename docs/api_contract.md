# API-контракт застосунку Flutter

## 1. Загальна інформація

Застосунок використовує локальне керування станом через клас `AppState`, який успадковується від `ChangeNotifier`.

**Тип взаємодії:** локальний API без HTTP-запитів.

**Основні сутності:**

- `User` - інформація про користувача.
- `Product` - інформація про товар.
- `AppState` - керування обраними товарами, кошиком і поточним користувачем.

## 2. Модель User

| Поле        | Тип      | Опис             |
| ----------- | -------- | ---------------- |
| `name`      | `String` | Ім’я користувача |
| `email`     | `String` | Електронна пошта |
| `avatarUrl` | `String` | URL аватара      |

Усі поля обов’язкові. Модель використовує незмінні поля `final`.

## 3. Модель Product

| Поле          | Тип      | Опис                            |
| ------------- | -------- | ------------------------------- |
| `id`          | `String` | Унікальний ідентифікатор товару |
| `name`        | `String` | Назва товару                    |
| `description` | `String` | Опис товару                     |
| `price`       | `double` | Ціна товару                     |
| `imageUrl`    | `String` | URL зображення                  |

Поля моделі незмінні (`final`).

## 4. Методи AppState

| Метод                              | Призначення                              | Результат                            |
| ---------------------------------- | ---------------------------------------- | ------------------------------------ |
| `setCurrentUser(User user)`        | Встановлює поточного користувача         | Оновлює стан                         |
| `toggleFavorite(String productId)` | Додає товар до обраного або видаляє його | Оновлює стан                         |
| `isFavorite(String productId)`     | Перевіряє, чи товар в обраному           | `bool`                               |
| `addToCart(Product product)`       | Додає товар до кошика                    | Оновлює стан                         |
| `removeFromCart(String productId)` | Видаляє перший знайдений товар із кошика | `bool`                               |
| `clearCart()`                      | Очищає кошик                             | Оновлює стан, якщо кошик не порожній |

Після успішної зміни стану відповідні методи викликають `notifyListeners()`. Віджети можуть слухати зміни та оновлювати інтерфейс.

## 5. Валідація та помилки

- Ім’я та email користувача не можуть бути порожніми.
- ID товару не може бути порожнім.
- Назва товару не може бути порожньою.
- Ціна товару повинна бути скінченним невід’ємним числом.
- Для порожнього ID у `isFavorite()` повертається `false`.
- Для порожнього ID або відсутнього товару в `removeFromCart()` повертається `false`.
- Некоректні дані в методах встановлення користувача та додавання товару призводять до `ArgumentError`.

## 6. Потік даних

1. Користувач взаємодіє з віджетом.
2. Віджет викликає відповідний метод `AppState`.
3. `AppState` перевіряє дані та змінює стан.
4. `notifyListeners()` сповіщає слухачів про зміни.
5. Інтерфейс оновлюється відповідно до нового стану.

## 7. Обмеження

На цьому етапі дані зберігаються лише в пам’яті застосунку. Після перезапуску застосунку стан не зберігається. Віддалений сервер і HTTP API не реалізовані.
